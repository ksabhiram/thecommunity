Room Temperature Synthesis Calculator

Lab-sheet method: fixed solvent volume, molar ratios × a multiplication factor give strengths, weigh-out masses and the synthesis yield. Type only the formulas, and molecular weights are worked out for you.

1. Batch setup

Strength (mol/L) = molar ratio × multiplication factor. Mass = MW × strength × volume ÷ 1000. Brackets and partial values are read exactly: (NO3)3 counts NO₃ three times and Bi0.45Sb1.55Te3 keeps its decimals. Values change only when you type them, click a field to reveal its small arrows, or use the ↑ / ↓ keys (hold Shift for ×10). The mouse wheel never changes a value.

2. Reagents

Reagent formulaMW (g/mol)Molar ratioPurity %Strength (M)Mass to weighRoleElement mass
The molecular weight fills in automatically from the formula. If your lab sheet uses a different value you can type over it, and clearing the box returns it to auto. Reagents that contain a product element feed the yield; anything else (KOH, NaBH₄) is weighed but not counted.

How this relates to the lab sheet

Column by column
  • Strength = molar ratio × multiplication factor, i.e. concentration in the water.
  • MW × S × Vol ÷ 1000 = grams of reagent to weigh (divided by purity if below 100 %).
  • Pure solute MW ÷ MW = “Ratio”, the mass fraction of the product element in the reagent (Ag in AgNO₃ = 0.6350).
  • Yield = Ratio × mass, the grams of element delivered. The sheet's Total yield adds these up.
  • Added here: the limiting-reagent yield. The sheet adds all Ag and all Se, so a small Se excess is counted as product. The limiting-reagent value is the true stoichiometric maximum.

4. Molar ratio calculator (oxidation states)

A stand-alone tool. It does not use or change anything above. Enter the oxidation state before and after for each element, and it gives the electrons to supply and the molar ratio of reducing agent needed. Negative values are allowed (for example Se: 0 → −2).

Molecular Weight Calculator

Type any formula, including partial values like Bi2.3Te3, brackets like (NO3)3 and hydrates like CuSO4·5H2O. Choose how much compound you want and it tells you how much of each element to take, to 0.0001 g, with an optional purity correction.

1. Formula and amount

Brackets multiply everything inside them, so (NO3)3 counts NO₃ three times. Subscripts can be decimals. Put a hydrate last, after “·” or “.”. Elements with no standard atomic weight use the mass number of their longest-lived isotope. Values change only when you type them, use the small arrows that appear on a selected field, or press ↑ / ↓ (Shift for ×10).
